# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes e-commerce sales and customer transaction data to identify revenue trends, customer purchasing behavior, product performance, and opportunities for business improvement.

The project uses SQL, Python, Pandas, and Power BI to perform an end-to-end data analytics workflow.

## 🎯 Business Objectives

- Analyze overall sales and revenue performance
- Identify the highest-performing products and categories
- Analyze customer purchasing behavior
- Identify high-value and repeat customers
- Calculate key business KPIs
- Analyze monthly and yearly sales trends
- Identify patterns that can support business decisions

## 🛠️ Tools & Technologies

- SQL / MySQL
- Python
- Pandas
- NumPy
- Power BI
- Advanced Excel

## 📊 Project Workflow

1. Data Collection
2. Data Understanding
3. Data Cleaning
4. SQL Analysis
5. Exploratory Data Analysis
6. Customer & Product Analysis
7. Power BI Dashboard
8. Business Insights & Recommendations
